A single-line joke about office life, written for the make.fun bounty
"One-Line Office Jokes". The joke turns on a painfully specific office
ritual — the printer that only ever jams on the last page of a long report —
and lands the laugh in the final few words.

## Run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22, no dependencies, no network, fully deterministic) writes
one line of plain text to `/output/entry.txt`.
